# LangChain Console Based Projects 

## 📂 Folder Overview

* **3.EmbeddedModels** – Embeddings and vector representations
* **CHAINS_Langchain** – LangChain chains examples
* **Langchain_OutputParsers** – Structured outputs (TypedDict, Pydantic, JSON)
* **Langchain_Runnables** – Runnable pipelines and LCEL usage
* **Langchain_TextSplitters** – Document chunking strategies
* **Langchain_documentLoaders** – Loading data from different sources
* **Langchain_models** – LLM and model integrations

## ▶️ How to Run

1. Create & activate virtual environment
2. Install dependencies
3. Add API keys in `.env` file
4. Run files from terminal
